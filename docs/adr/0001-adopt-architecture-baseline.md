# ADR-0001: Принять ARCHITECTURE.md как нормативный фундамент проекта

- **Статус:** принято
- **Дата:** 2026-08-07
- **Затрагивает нормы:** все (G1–G24, C1–C24)

## Контекст

Проект — коммерческая визуальная новелла с горизонтом 5–10 лет и командой из сценаристов,
художников, motion-дизайнера, локализаторов и QA. Нужен фундамент, который расширяется
аддитивно (главы, персонажи, языки, DLC) без переписывания архитектуры.

## Решение

[docs/ARCHITECTURE.md](../ARCHITECTURE.md) принимается как нормативный документ.
Раздел 0 (решения G1–G24 и интеграционный канон C1–C24) — контракт: код, контент и процессы,
противоречащие ему, не проходят ревью. Изменение любой нормы — только через новый ADR
со ссылкой на заменяемую норму.

## Последствия

- Внедрение — строго по фазам раздела 8; фаза 0 (этот репозиторий) не содержит
  компиляции сцен, локализации и DLC — заглушки CLI честно называют номер фазы.
- Список движковых допущений ведётся в docs/adr/ по мере появления кода в
  `game/framework/00_core/engine_compat/` (G18).
