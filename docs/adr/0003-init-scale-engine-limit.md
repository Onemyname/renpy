# ADR-0003: Init-шкала начинается с −999 — движок ограничивает приоритеты диапазоном −999..999

- **Статус:** принято
- **Дата:** 2026-08-07
- **Затрагивает нормы:** C8

## Контекст

Первый прогон настоящего `renpy lint` (SDK 8.5.3) на скелете фазы 0 показал:
`The init priority (-1000) is not in the -999 to 999 range` — канон C8 задавал ядру
приоритет −1000, но Ren'Py резервирует значения за пределами −999..999 за собой.

## Решение

Шкала C8 сдвигается: **ядро −999**, stores −980, engine_compat −950, build_info −900,
реестры −100, темы −60…−50, styles/screens 0, контентные define 500, DLC-слоты 999
(999 — валидная граница). Код framework и текст ARCHITECTURE.md приведены к −999.

## Последствия

- Верхняя граница 999 (DLC-слоты) остаётся впритык к пределу — новые уровни выше DLC
  не заводить; если понадобится, сдвигать DLC вниз.
- Урок для G18: даже «очевидные» константы проверяются реальным движком, а не только ревью.
