# ADR-0006: Production-конвейер DAZ→ComfyUI→ffmpeg, provenance и релизные флейворы

- **Статус:** принято
- **Дата:** 2026-08-08
- **Затрагивает нормы:** G2 (новые зоны сырцов), G9 (паки: nsfw), G13 (новые трансформации), G19 (видео-бюджеты), G21 (внешние зависимости-модели), раздел 2 (конвейер ассетов), раздел 7 (релизы)

## Контекст

Арт-направление проекта зафиксировано: **DAZ Studio (реализм, стиллы) + AI-анимация
(ComfyUI/Wan 2.2, I2V) + видео-вставки WebM в Ren'Py**. Дистрибуция — по модели
подписки: ранние patron-сборки с полным контентом и публичные SFW-сборки.
Скелету конвейера не хватало: видео-трека, категории CG, следов происхождения
генеративных ассетов (без них ассет невоспроизводим), релизных флейворов и
отделения NSFW-контента.

Требование-рамка: НЕ переписывать архитектуру — расширять существующий
data-driven конвейер (манифесты, контентно-адресуемый кэш, реестр схем G16,
единый CLI G1).

## Решение

### 1. Зоны и треки (расширение G2/раздела 2)

```
assets_src/daz/**/<name>.render.yaml   # декларация рендера (daz_render@1); .duf — через vn assets push
assets_src/png/cg/**                   # CG-стиллы (рендеры/AI) -> game/assets/cg/** (webp)
assets_src/video_src/<group>/**        # видео-сырцы (+<name>.video.yaml, video_src@1)
                                       #   -> game/assets/mov/**.webm + .webm.meta.json (mov_meta@1)
```

Новые трансформации в том же кэше G13: `png2webp_cg@1`, `video2webm@1`
(версия = пресет ffmpeg; sidecar-опции входят в ключ кэша). Production-пресет
видео зафиксирован под Ren'Py: **WebM + libvpx-vp9 + yuv420p, чётные размеры,
без аудио** (лупы немые). Loop-валидация — в тулинге (`vn assets video
build|validate`): ffprobe-свойства + RMS-стык первого/последнего кадров.
Компилятор эмитит `image cg <...>` и `image mov <...> = Movie(...)` из
собранных зон — как sprite_tree, без ручной регистрации.

### 2. Provenance: хэш источника → параметры → хэш артефакта

Каждый нетривиальный сырец несёт `<file>.provenance.json` (provenance@1):
цепочка шагов `daz_render | comfyui | manual`. Шаг comfyui извлекается из
PNG-метаданных ComfyUI автоматически (workflow, seed, модель, LoRA+веса,
промпты, sampler/steps). Дальше по конвейеру провенанс продолжают манифест
сборки ассетов и mov_meta@1 — **второй системы метаданных нет**. Проверка —
`vn assets provenance verify` (хэши против локальных файлов или манифестов
хранилища) и `vn assets daz validate` (декларации рендеров), обе входят в
релизный гейт.

### 3. Окружение как зависимость (расширение G21-логики на инструменты)

DAZ/ComfyUI/ffmpeg/модели — внешние зависимости уровня SDK: описаны манифестом
(`tools/comfyui-models.yaml`, comfyui_models@1), ставятся скриптами
(`tools/setup-comfyui.ps1`, `tools/install-daz.ps1`), проверяются `vn pipeline
doctor` (PASS/WARN/FAIL). Загрузчик моделей не обходит логины/лицензии
(auth: manual = честная остановка с инструкцией). Пути не хардкодятся:
PATH + `VN_FFMPEG`/`VN_FFPROBE`/`VN_COMFYUI`.

### 4. Флейворы и NSFW-пак (раздел 7, G9)

`project.yaml: flavors.<id> = {packs, nsfw, early_content, watermark}`.
`vn release build --flavor <id>`: гейт (`vn release validate`) →
`game/build_id.json` (build_info@1: build_id = `version+sha.flavor.timestamp`,
опциональный patron_token) → `vn package` → `build/dist/<version>-<flavor>/`.
Файл флейвора живёт **только на время distribute** — dev-чекаут всегда flavor=dev.

- NSFW-контент отделён с первого дня: пак `nsfw` + конвенция подпапки
  `nsfw/` в категориях ассетов; SFW-флейворы исключают `game/assets/*/nsfw/**`
  на этапе distribute (глобы считает тулинг, options.rpy исполняет).
- Скрипты паков грузятся всегда (G9) — файлы сцен не исключаются; гейт
  логический: `vn_build.nsfw / early_content` + `pack_registry.owned()`.
  Депот-уровневое разделение сцен — фаза 3 (Steam).
- Вотермарка: полупрозрачный build-id оверлеем, только при `watermark: true`
  (трассировка утечек patron-сборок). Никакого рантайм-трекинга.

### 5. Бюджеты (G19)

`video_total_mb` (300) и `video_file_mb` (40) — отдельная ветка бюджета;
`assets_total_mb` поднят 200→500 (статикой видео-мегабайты не оправдать).
Единая точка `release.budget_failures()` — и в `vn build`, и в релизном гейте.

## Последствия

- Любой стилл/луп в игре прослеживается до .duf/workflow и воспроизводим;
  цена — дисциплина сайдкаров (record при генерации), её проверяет гейт.
- ffmpeg становится обязательным при наличии видео-сырцов (в CI установлен;
  локально — `vn pipeline doctor` подскажет).
- Правка пресета энкода = бамп `video2webm` в TRANSFORMS (иначе кэш отдаст
  старьё) — зафиксировано комментарием в коде.
- NSFW-конвенция (подпапка `nsfw/`) — публичный контракт для художников;
  нарушение = 18+ контент в public-сборке. Гейт ловит только соответствие
  каталогам, не содержимое — ревью контента остаётся на людях.
- Модели (~37 ГБ) не в git и не в vn-assets-store: восстанавливаются
  `vn pipeline models --pull` из первоисточников по манифесту. Если апстрим
  удалит файл — манифест меняется отдельным PR (fallback: локальные бэкапы).
- План отступления: видео-трек и флейворы — аддитивные ветки конвейера;
  отключение = удаление сырцов/флейворов, ядро сборки не затронуто.
