# Онбординг: сценарист

> Фаза 0: инсталлер по ролям появится в фазе 1 (G22). Пока — ручные шаги ниже.
> Метрика готовности тулинга: от чистой машины до «правка реплики видна в игре» < 1 дня.

## Установка

```bash
git clone <repo> vn && cd vn
pip install -e tools/vn
vn doctor
```

## Что вы делаете

- Пишете сцены: пара файлов `content/chapters/<ваша глава>/scenes/sNNN_slug.scene.{yaml,rpy}`
  (`vn scene new` — с фазы 1). Диалоги — обычный Ren'Py-скрипт; метки только `<full_id>__*`;
  переходы между сценами — `return "<exit_id>"` + `exits:` в YAML.
- Мержите главу в main ежедневно со `status: draft` — граф-проверки для draft это warnings.

## Что вы никогда не делаете руками

Правка `game/generated/`, `game/assets/`, `game/tl/`; label вне `<full_id>__*`;
прямые `jump` в чужие сцены; переиспользование id; редактирование чужой главы без approve владельца.
