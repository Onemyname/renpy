# Онбординг: локализатор

> Фаза 0: конвейер локализации (раздел 5 ARCHITECTURE.md) появится в фазе 2. Контракт заранее:

- Источник истины переводов — PO-файлы в `loc/po/<lang>/` (gettext, msgctxt с контекстом:
  сцена, говорящий, скриншот-референс).
- `game/tl/` целиком генерируется `vn loc import` — ручные правки запрещены и ловятся CI.
- Идентификаторы строк стабильны (say-id в исходниках): правка опечатки в оригинале
  не теряет ваш перевод.
- Покрытие по языкам/главам — `vn loc report`; релизный гейт блокирует релиз при покрытии
  ниже порога из `loc/loc.yaml`.
