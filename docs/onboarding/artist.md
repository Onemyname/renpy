# Онбординг: художник / motion-дизайнер

Этот документ — **контракт на ассет**. Всё, что здесь написано, проверяется
автоматически (`vn assets validate`, `vn build`, CI): нарушение — красная сборка
с текстом ошибки, а не замечание арт-директора и не тихая пропажа файла.

## Правила, действующие с первого дня

- Вы никогда не кладёте файлы в `game/` — путь ассета: `assets_src/` → пайплайн → `game/assets/`.
- Растр, аудио и видео в `assets_src/` идут в **Git LFS** (`.gitattributes`); бинарь мимо
  LFS — ошибка линтера: он осел бы в истории git целиком и навсегда.
- Не-растровые гиганты (PSD, Tray-бандлы Sims 4, `.duf`-сцены DAZ) — в хранилище через
  `vn assets push` / `vn assets pull`; локи обязательны (G14).
- Имя каждого сегмента пути — `^[a-z][a-z0-9_]*$`: строчные, цифры, `_`.
  Ни пробелов, ни дефисов, ни CamelCase. `Screenshot 2026-08-09.png` не соберётся.

## Разрешения: снимайте в 4K с первого дня

**Уменьшить можно всегда, увеличить — никогда.** Игра сегодня отгружает и 1080p,
и 4K одновременно, а движок сам выбирает вариант по монитору игрока
(ADR-0012). Переключение «шипим только 1080p» ↔ «шипим 4K» — правка
`project.yaml: render`, а не пересъёмка.

| Класс | Мастер | Что уедет в игру |
|---|---|---|
| Фон (`bg`) | **3840×2160**, ровно 16:9 | `day.webp` 1920×1080 + `day@2.webp` 3840×2160 + миниатюра |
| CG (`cg`) | **3840×2160**, ровно 16:9 | то же |
| Спрайт (`spr`) | **2× экранной вёрстки**: рост персонажа ≈1100 px на экране → холст ≈2200 px | `base.webp` 600×1100 + `base@2.webp` 1200×2200 |
| Видео (`mov`) | ≤1920×1080, луп ≤30 c | `name.webm` (VP9) + постер-кадр |

Мастер меньше отгружаемого размера — **ошибка** (апскейл запрещён). Мастер ровно
1× — соберётся, но вы получите предупреждение «вариант @2 не собран»: на 4K игра
останется на растянутом 1080p.

Актуальные числа всегда в `project.yaml: render` — не переписывайте их сюда.

## Форматы

| Класс | Мастер | Почему так |
|---|---|---|
| `spr` | `png`, `webp`, `tif`, `tiff` | нужна альфа; у JPEG её нет физически |
| `bg`, `cg` | `png`, **`jpg`**, `webp`, `tif`, `tiff` | прозрачности нет — JPEG уместен |
| `mov` | `mp4`, `mov`, `mkv`, `webm`, `m4v`, `avi` | перекодируется всё равно |

Файл неподходящего формата **не пропадает молча** — он называет себя ошибкой.
Файл в зоне мастеров, который не подобрала ни одна ветка конвейера, — тоже ошибка.

## Прозрачность

- **Спрайты обязаны иметь вырезанный фон.** RGBA с полностью непрозрачной альфой —
  это скриншот, у которого фон не вырезали; сборка его отвергнет.
- Слои одной позы обязаны лежать на **одном холсте**: layeredimage складывает их
  в `(0, 0)`, разный холст смещает наряд и эмоцию относительно тела. Холст
  объявляется в `content/characters/<id>/character.yaml: canvas` и проверяется.
- У фонов и CG альфа не нужна — она будет отброшена (это ~20 % веса файла).

## Дерево мастеров

```
assets_src/art/
  characters/<char>/
    <pose>/                       # поза: stand, sit, lean …
      base.png                    # ОБЯЗАТЕЛЕН: тело в позе
      outfits/<outfit>.png        # полный холст позы, альфа
      faces/<emotion>.png         # полный холст позы, альфа
      overlays/<name>.png         # накладки: слёзы, румянец, пот — СОЧЕТАЮТСЯ
    side/<name>.png               # портреты say-окна; side/base.png — основной
  backgrounds/<...>/<name>.jpg    # вложенность разрешена: apartment/living_room/day.jpg
  cg/<...>/<name>.png             # вложенность произвольная
  cg/nsfw/<...>                   # 18+ ТОЛЬКО здесь — public-сборка вырезает по этому пути
assets_src/video_src/<group>/<name>.mp4   # группа обязательна
assets_src/audio_stems/{bgm,amb,sfx}/<id>.ogg
```

Вложенность каталогов фонов — организационная: id локации остаётся плоским
(`apartment_living_room`), а `location.yaml` ссылается на путь файла.

`assets_src/png/` продолжает работать как исторический алиас `art/`.

## Что делает конвейер за вас

Не создавайте производные версии руками — их сделает сборка:

- уменьшенные варианты (`@1` из 4K-мастера) и оверсэмпл-варианты (`@2`);
- миниатюры для сетки галереи (`<name>.thumb.webp`);
- постер-кадр видео (`<name>.poster.webp`) — он же заглушка `Movie(image=)`,
  он же превью в галерее: **ручной `thumb` у видео больше не нужен**;
- нарезка PSD по конвенции слоёв (`assets_src/psd/characters/<key>/<key>_<pose>.psd`);
- склейка PNG-секвенции в видео-мастер: `vn assets video seq <кадры> assets_src/video_src/<group>/<name>.mp4`.

## Рендеры и видео (DAZ/AI-конвейер, ADR-0006)

- Окружение (DAZ Studio, ComfyUI, ffmpeg, модели) — по `docs/pipeline/phase-0.md`;
  самопроверка: `vn pipeline doctor`.
- Каждый DAZ-рендер объявлен: `assets_src/daz/**/<имя>.render.yaml` (сцена, камера,
  свет, разрешение, пресеты персонажей). `vn assets daz validate` проверит и запишет провенанс.
- AI-обработка (ComfyUI): выходной PNG не переименовывать до
  `vn assets provenance record <файл> --source <исходник>` — параметры генерации
  (seed, модель, LoRA, промпты) извлекаются из метаданных файла автоматически.
- **Virt-a-Mate** — опциональный третий источник (физика тел): `assets_src/vam/**/<имя>.render.yaml`
  (`vam_render@1`), захват в `art/cg/**` / `video_src/**`; `vn assets vam validate`.
- **The Sims 4** — опциональный четвёртый источник (ADR-0007): `assets_src/sims4/**/<имя>.render.yaml`
  (`sims4_render@1`), `vn assets sims4 validate`. В декларации **обязательна `game_version`**:
  патчи EA меняют картинку.
- **Лицензии — до первого рендера.** Купили ассет → сразу запись в `content/licenses.yaml`
  (SKU, тип лицензии, инвойс, `game_use`, `nsfw_allowed`), в декларации — `license: [...]`.
  Ассет с `game_use: false` блокирует сборку.

## Самопроверка перед пушем

```bash
vn assets validate     # формат, разрешение, альфа, имена, свежесть, ссылки контента
vn assets memory       # во что обходится худшая сцена и влезает ли она в кэш образов
vn build               # полная сборка + бюджеты
```

Сообщение об ошибке всегда называет файл, нарушенное правило и то, где это правило
записано. Если ошибка непонятна — это баг конвейера, заводите issue.

## Чего делать нельзя

- Переименовывать ассет, который уже был в релизе, без записи в `content/renames.yaml: assets`.
  Галерея открывает картинки по имени образа — переименование стирает игроку открытый кадр.
- Класть 18+ вне `nsfw/`-подпапки: он уедет в публичный билд.
- Апскейлить мастер, чтобы «пройти проверку размера»: вы получите мыло вместо 4K.
- Складывать в зону мастеров рабочие файлы (`.psd` рядом с фоном, черновики):
  всё, что не подобрано конвейером, — ошибка сборки.
