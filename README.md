# VN — производственный фреймворк коммерческой визуальной новеллы на Ren'Py

Это не «игра на Ren'Py», а **monorepo производственного конвейера**, из которого
игра собирается: декларативный контент, собственный Content Compiler, ассет-конвейер
под фотореалистичный рендер (DAZ / VaM / Sims 4 / I2V-видео), локализация,
озвучка, сейв-миграции, релизные флейворы и QA-автоматизация — всё под одним CLI `vn`.

Нормативный фундамент — **[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)**
(решения G1–G24 и канон C1–C24 в разделе 0 — контракт: код и процессы,
противоречащие им, не проходят ревью; изменение нормы — только через ADR).
Практический справочник «как здесь что-то сделать» —
**[docs/handbook/](docs/handbook/README.md)** (описывает код, который есть сегодня).

## Три кита

1. **Data-driven контент.** Новая глава = папка `content/chapters/chNN_slug/`
   с YAML-декларациями и авторскими `scene.rpy`. Меню, галерея, локализация,
   сейв-схема и билд обновляются сами — ручной регистрации не существует.
2. **Кодогенерация вместо runtime-магии.** Content Compiler превращает
   декларации в обычный статический `.rpy` на сборке. Движок получает то, с чем
   он хорошо работает — статические label, `layeredimage`, `default` — поэтому
   save/rollback/prediction/lint работают штатно, без хаков и монкипатчей.
3. **Валидация до мержа.** Схемы, граф сцен и достижимость, ссылки на
   образы/треки/реплики, реестр переменных, неизменяемость выпущенных id,
   бюджеты размера и памяти кэша — всё ловит сборка и CI, а не игрок.

## Что уже работает

| Подсистема | Суть |
|---|---|
| Content Compiler | пары `scene.yaml`+`scene.rpy` → генерат с обвязкой; переходы только `return "<exit>"` — граф истории статически известен |
| Ассет-конвейер | мастера `assets_src/` → `game/assets/` (WebP/WebM + `@N`-оверсэмпл под физический экран); контент-адресуемый кэш; провенанс и лицензии AI-контента |
| Персонажи | `character.yaml` + matrix поз/нарядов/эмоций → `layeredimage`; полнота комбинаций проверяется на сборке |
| Послойные шоты | кинематографический кадр = env-подложка + вырезанные слои; наряд меняется переменной гардероба без перерендера кадра ([ADR-0013](docs/adr/0013-layered-shots.md)) |
| Озвучка | voice-манифесты по главам×языкам; компилятор эмитит `voice`-операторы по стабильным id реплик; транскод в Opus + гейт покрытия в релизе |
| Аудио | каналы bgm/ambient/sfx/voice, дакинг музыки под голос, валидация «kind трека ↔ канал» |
| Локализация | стабильные id строк (`vn loc keys`), gettext PO, пер-языковые шрифты, псевдолокаль, гейт покрытия |
| Сейвы | версионированная схема + цепочка миграций; сейв из будущего отвергается; выпущенные id неизменяемы (реестр + shim-метки) |
| Галерея/ачивки | декларации + авто-анлок фактом просмотра (`persistent._seen_images`) |
| Паки/DLC | `packs/<id>/` зеркалит `content/`; владение — логический гейт `pack_registry.owned()` |
| QA | автопилот внутри процесса игры (скриншоты, smoke, сейв-корпус с миграциями), бюджеты перфа в CI |
| Релиз | флейворы (public/patron) из `project.yaml`, релизный гейт `vn release validate`, ассеты россыпью ради Steam-дельта-патчей |

## Быстрый старт

```bash
git lfs install                  # ОДИН раз на машину: шрифты и демо-мастера в LFS
git clone https://github.com/Onemyname/renpy vn && cd vn && git lfs pull
pip install -r tools/vn.lock && pip install -e "tools/vn[dev]"
export RENPY_SDK=~/renpy-8.5.3-sdk    # SDK с renpy.org, версия пиннована в project.yaml

vn doctor                        # самодиагностика окружения с рецептами
vn build                         # схемы → lint → ассеты → генерат → бюджеты
vn play                          # запуск игры
vn test smoke                    # автопрохождение с скриншотами
python -m pytest tools/vn/tests -q   # 240 passed
```

Без `git lfs` шрифты приедут текстовыми указателями и игра упадёт на старте —
`vn doctor` ловит это отдельной проверкой и печатает рецепт.

## CLI

Все инструменты — один пакет `tools/vn/` (G1): `vn bootstrap|doctor|dev|build|play|package`,
`vn content …` (lint/compile/graph), `vn assets …` (build/video/provenance/memory),
`vn scene|chapter|char …`, `vn loc …` (keys/extract/import/report),
`vn voice …` (manifest/import/validate), `vn save …` (check/corpus),
`vn test …` (smoke/oversample), `vn release …` (validate/build/changelog), `vn pack …`.
CI-режим везде — флаг `--check`. Exit-коды: 0 успех, 1 ошибка, 2 usage, 3 «не реализовано в этой фазе».

## Что вы никогда не делаете руками

- не правите `game/generated/`, `game/assets/`, `game/tl/` — производные зоны, их перезапишет сборка;
- не пишете label вне контракта `<full_id>__*` в сценах и не делаете `jump` между сценами;
- не переиспользуете и не переименовываете выпущенные id (сцен, глав, персонажей, переменных, ассетов) — только `content/renames.yaml`;
- не регистрируете образы/треки/экраны вручную — всё эмитит компилятор из деклараций;
- не пушите сырцы без лока (`vn assets push` без лока откажет).

## Карта репозитория

| Зона | Что это |
|---|---|
| `content/` | Источник истины: декларации (YAML со `schema:`) + авторские `scene.rpy` |
| `packs/` | DLC-контент: один пак = одно дерево, зеркалящее `content/` |
| `assets_src/` | Мастера ассетов: растр/аудио/голос/видео в LFS, гиганты (PSD, DAZ-сцены) — в S3 по манифестам |
| `game/framework/` | Рукописный код надстройки: `00_core` (фасад `vn.*`, state, flow, audio), `20_ui`, `90_debug` |
| `game/generated/` | Генерат Content Compiler — **не в git**, `vn build` |
| `game/assets/` | Собранные ассеты — **не в git**, `vn assets build` |
| `loc/` | Обмен с переводчиками: PO-файлы + шардированный ledger строк |
| `tools/vn/` | Единственный CLI проекта + 240 pytest-тестов |
| `tools/schemas/` | Реестр JSON Schema (39 схем) — единственный источник версий деклараций |
| `ci/` | Фикстуры сейв-корпуса, линия `.rpyc` для save-совместимости, релизный манифест |
| `docs/` | [ARCHITECTURE](docs/ARCHITECTURE.md) · [handbook](docs/handbook/README.md) · [ADR](docs/adr/) · [конвенции](docs/conventions/) · [онбординг по ролям](docs/onboarding/) · [runbooks](docs/runbooks/) |

## Качество и CI

Каждый пуш: lint схем и контента → `vn build` (включая бюджеты G19 и модель
памяти кэша образов) → `vn loc keys --check` → движковый `renpy lint` →
`vn test oversample` → `vn content compile --check` → pytest. Ночью — полный
smoke по веткам и языкам + сейв-корпус; еженедельно — canary на свежем Ren'Py
против пина. Релиз собирается **только** через `vn release build` (гейт
`vn release validate` красный — дистрибутива нет).
