# ci/

Скрипты проверок CI (фаза 1+: smoke затронутых глав под xvfb, bootstrap-джоба
«clone → запуск ≤ 5 минут», сейв-корпус `ci/fixtures/saves/`, weekly canary на свежем Ren'Py).

Конфиги пайплайнов — `.github/workflows/` (`ci`, `nightly`, `canary`, `release`,
`steam-upload`), и они единственные: GitLab-зеркало выведено из эксплуатации
2026-08-18 — три джобы против восьми (ни LFS, ни ffmpeg, ни локализационных
проверок, ни smoke, ни сейв-корпуса, ни релиза), при этом документация называла
главным именно его. Вся логика живёт в CLI
`vn`, поэтому перенос на другую систему CI — это те же команды в её конфиге, а не
второй файл про запас; что второго конфига нет, стережёт
`tools/vn/tests/test_ci_config.py::test_no_second_ci_platform_config`.
