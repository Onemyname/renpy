# 10_systems/ — gameplay-системы (слой 1)

Плагины поверх ядра (правило 1.8): `10_systems/<mechanic_id>/`, регистрация декларативно
через `vn.register_system("<id>", ...)`, общение между системами — только через события ядра.
Система удаляема: выпил папки ломает компиляцию только глав, объявивших `requires: [<id>]`.

Первые системы (relationship, gallery, minigame_host) появятся в фазе 1–2.
